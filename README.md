5.What are univariate, bivariate, and multivariate analyses?

Univariate: Analysis of a single variable.
Bivariate: Analysis of two variables.
Multivariate: Analysis of more than two variables simultaneously.

6.Difference between heatmap and pairplot?

Heatmap: Visualizes correlation or values in a matrix format.
Pairplot: Plots pairwise relationships between all variables in a dataset.
